## Problemas encontrados y lecciones
1. **React Compiler:** un valor que puede ser `null` no se desreferencia dentro de `useCallback`/`useMemo`, y los cambios de hooks se comprueban arrancando la app, no solo con Jest. Guardado también en la memoria del proyecto.
2. **Iconos:** comprobar que un icono existe en la versión instalada de `@tabler/icons` antes de usarlo.
3. **Cambiar la forma de un resultado** rompe las pruebas que lo comparan exacto (pasó con `postman-script-report`).
4. **Tras tocar un convertidor** hay que ejecutar `npm run build:bruno-converters` para que la app y la CLI lo vean.
5. **Herramientas:** el modo automático de Claude Code dejó sin veredicto a la herramienta de comandos durante un rato (error transitorio del servicio de permisos, ajeno a la shell del usuario); se retomó al recuperarse, ejecutando los comandos con `!` mientras tanto.
6. **Regla de commits:** el roadmap pide commits sin `Co-Authored-By`; se siguió el roadmap.
